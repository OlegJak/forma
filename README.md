# FORMA

[Открыть платформу](https://forma.yakimush-oleg.workers.dev) · [Демокабинет](https://forma.yakimush-oleg.workers.dev/demo)

Платформа онлайн-записи для небольших компаний, у которых нет собственного сервиса бронирования. Концепт для портфолио: публичный каталог, отдельные страницы компаний, Google-вход и кабинет владельца.

## Что работает

- Каталог компаний с поиском, категориями и фильтром по городу.
- Страница `/studio/<slug>` с услугами, командой, календарём и свободными слотами.
- Запись без регистрации; после Google-входа — список личных записей.
- Владелец создаёт компании, добавляет и архивирует услуги/специалистов, задаёт часы и рабочие дни, видит и отменяет записи.
- Проверка принадлежности услуги и мастера компании, изоляция данных по владельцу.
- Защита от двойной записи: проверка пересечения и вставка выполняются одной атомарной SQL-командой.
- CSRF-защита, HttpOnly/SameSite cookie, CSP и ограничение попыток бронирования.
- Демокабинет `/demo` без входа, только вымышленные данные, без права изменять компании.
- Сервер не засыпает: Cloudflare Workers отвечает сразу, без «холодного старта».

## Стек

Cloudflare Workers · TypeScript · Cloudflare D1 (SQLite) · Google OpenID Connect · HTML/CSS/JavaScript без фреймворка и сборки. Шрифт Inter (SIL OFL) раздаётся с того же домена.

## Локальный запуск

Нужен Node.js 22+:

```sh
npm install
npm test
npm run dev
```

Открыть [localhost:8787](http://localhost:8787). Без ключей Google работают каталог, запись и демокабинет. Для входа через Google скопируйте `.dev.vars.example` в `.dev.vars` и заполните ключи.

## Размещение

[Пошаговая настройка Cloudflare и Google](docs/DEPLOY.md). Схема базы и демоданные — в `migrations/`, тесты API — в `test/`, GitHub Actions запускает проверку типов и тесты.

Демонстрационные компании и сотрудники вымышлены. Используйте тестовые имя и телефон. Для настоящих клиентов сначала устраните ограничения, перечисленные в [DEPLOY.md](docs/DEPLOY.md#ограничения-концепта).

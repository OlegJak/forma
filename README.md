# FORMA

[Открыть публичную платформу](https://forma-booking.onrender.com) · [Демокабинет](https://forma-booking.onrender.com/demo)

Платформа онлайн-записи для небольших компаний, у которых нет собственного сервиса бронирования. Концепт для портфолио: публичный каталог, отдельные страницы компаний, Google-вход и кабинет владельца.

## Что работает

- Каталог компаний с поиском, категориями и фильтром по городу.
- Страница `/studio/<slug>` с услугами, командой, календарём и свободными слотами.
- Запись без регистрации; после Google-входа — список личных записей.
- Владелец создаёт компании, добавляет и архивирует услуги/специалистов, задаёт часы и рабочие дни, видит и отменяет записи.
- Проверка принадлежности услуги и мастера компании, изоляция данных по владельцу.
- Защита от двойной записи: транзакционная блокировка компании и проверка пересечения интервалов в БД.
- CSRF-защита форм, HttpOnly/SameSite session cookie, Secure cookie в production, CSP и базовое ограничение попыток бронирования.
- Демокабинет `/demo` без входа, только вымышленные данные, без права изменять компании.
- H2 локально; PostgreSQL/Supabase для размещения.

## Стек

Java 21 · Spring Boot 3.5 · Spring Security OAuth2/OIDC · JDBC · PostgreSQL/H2 · HTML/CSS/JavaScript. Без frontend-фреймворка и сборки npm.

## Локальный запуск

Нужны JDK 21 и Maven 3.9+:

```sh
mvn test
mvn spring-boot:run
```

На машине разработки JDK и Maven лежат в игнорируемой папке `.runtime`; для запуска доступен `./run.sh`. Открыть [localhost:8080](http://localhost:8080).

Без OAuth-ключей работают каталог, демозапись и демокабинет. Реальный вход и управление компаниями доступны после установки `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `BASE_URL` и перезапуска. Нет скрытого входа под администратором и имитации Google-регистрации.

## Данные

База локально: `data/forma.mv.db`; папка исключена из Git и Docker-контекста. При первом запуске старые записи `data/bookings.tsv` переносятся в компанию FORMA; исходный файл сохраняется. Резервная копия первой версии — `backups/forma-before-platform.tar.gz`, не публикуется.

Демонстрационные компании и сотрудники вымышлены. Используйте тестовые имя и телефон. Для настоящих клиентов сначала устраните ограничения, перечисленные в [DEPLOY.md](docs/DEPLOY.md#ограничения-концепта).
